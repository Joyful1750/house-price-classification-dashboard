# House Price Classification Dashboard

Interactive Streamlit dashboard for the house-price classification practice project.

## Included
- Data exploration
- Welch t-tests
- Logistic regression
- Coefficients and odds ratios
- Training vs test evaluation
- Confusion matrix
- ROC curve and ROC-AUC
- Individual-house prediction
- Test-customer predictions
- Downloadable 0/1 prediction CSV

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

The dashboard expects `house_train.csv` and `house_test.csv` in the same folder as `app.py`.
